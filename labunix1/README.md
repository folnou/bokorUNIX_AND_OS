# build.sh

POSIX-совместимый shell-скрипт для сборки одного исходного файла — программы на C/C++ (`gcc` / `g++`) или документа TeX (`pdflatex`).

## Использование

```bash
./build.sh path/to/source.c
Как это работает
 1)Ищет в исходном файле строку-комментарий Output: имя_файла и берёт из него имя результата.
 2)Создаёт временный каталог через mktemp -d.
 3)Копирует исходник и собирает его внутри временного каталога (тип определяется по расширению: .c, .cpp / .cc / .cxx, .tex).
 4)Копирует готовый результат рядом с исходным файлом под именем из `Output:`.
 5)Временный каталог удаляется при любом исходе — успехе, ошибке сборки или получении сигнала (INT, TERM, HUP, QUIT, PIPE, ALRM, USR1, USR2).
Коды возврата 
======================

| Код | Причина                                                              |
|-----|----------------------------------------------------------------------|
| 0   | Сборка успешна                                                       |
| 1   | Неверные аргументы / файл не найден или не читается / mktemp failed  |
| 2   | Директива 'Output:' не найдена или содержит некорректное имя файла   |
| 3   | Неподдерживаемое расширение файла (не .c/.cpp/.cc/.cxx/.tex)         |
| 4   | Ошибка компиляции или сборки (gcc/g++/pdflatex вернул ошибку)        |
